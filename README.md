# DevEveryday Labs · Showcase Portal

Engineering Capability Showcase & Interactive Demos for DevEveryday. Built with **Hallmark Anti-AI-Slop Design Discipline** (Modern-Minimal / Cobalt Theme) to showcase 6 core delivery capabilities matching the DevEveryday Organization requirements.

🌐 **Linked Main Organization**: [dev-everyday-kappa.vercel.app](https://dev-everyday-kappa.vercel.app/)

---

## 🚀 6 Core Categories Covered

1. **01 / Landing Page**: Witachai Motion Portfolio & Kinetic Storefront (Next.js 16, React 19, Three.js Particle, GSAP, 100/100 Core Web Vitals)
2. **02 / Learning Platform**: PISA AI Grader & Assessment Engine (Next.js, Prisma, Google Cloud Vision AI, Automated Rubric)
3. **03 / Web Application**: Service Repair Management Hub (Next.js 15, Prisma, RBAC Admin/Technician, Queue Kanban)
4. **04 / E-commerce**: FR-Flower Omnichannel & POS Retail Engine (Next.js, Dynamic Cart, Delivery Matrix, PromptPay QR)
5. **05 / API & Backend**: Vehicle Inspection Mesh & High-Load Microservices (NestJS, gRPC, PostgreSQL, Docker, Event Queues)
6. **06 / 3D & Motion**: 3D Virtual Try-On & Digital Wardrobe (Vanilla Three.js Core Engine, Interactive 360° Mannequin for Chubby Man)
